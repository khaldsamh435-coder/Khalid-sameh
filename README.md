### منصة محور للصف الثاني بكالوريا

منصة تعليمية عربية تهدف إلى تبسيط قواعد النحو وتقديم الدروس التعليمية بطريقة واضحة وسهلة الاستخدام، مع قسم اختياري لتعلّم تصميم المواقع.

### 🌐 رابط المشروع

### ✨ المميزات

* شرح مبسّط لدروس النحو باللغة العربية.

* دعم اتجاه الكتابة من اليمين إلى اليسار (RTL).

* تصميم متجاوب مع الهواتف والأجهزة اللوحية والحواسيب.

* تنظيم الدروس لتسهيل الوصول إلى المحتوى.

* دعم الوضع الداكن.

* إمكانية تثبيت المنصة كتطبيق ويب تقدمي (PWA).

* تحسين محركات البحث (SEO).

* قسم اختياري لتعلّم تصميم المواقع باستخدام HTML وCSS.

* أمثلة برمجية قابلة للنسخ والتجربة.

### 📚 محتوى المنصة

دروس النحو

* الممنوع من الصرف.

* الأسماء الخمسة.

* البدل.

* النعت.

تصميم المواقع

* HTML5.

* CSS3.

* أمثلة عملية وتطبيقات تعليمية.

### 🛠️ التقنيات المستخدمة

* HTML5

* CSS3

* JavaScript

* Progressive Web App (PWA)

* Vercel

### 🎯 هدف المشروع

توفير تجربة تعليمية عربية سهلة ومنظمة تساعد الطلاب على فهم قواعد النحو، مع إتاحة محتوى إضافي للمبتدئين في مجال تصميم وتطوير المواقع.
