# منصة دروس النحو للصف الثاني بكالوريا

منصة تعليمية عربية تهدف إلى تبسيط قواعد النحو وتقديم الدروس للطلاب من خلال واجهة واضحة وسهلة الاستخدام.

## 🌐 رابط المشروع
https://khalid-sameh.vercel.app/

## ✨ المميزات
- شرح دروس النحو باللغة العربية.
- دعم اللغة العربية واتجاه الكتابة من اليمين إلى اليسار (RTL).
- تصميم متوافق مع الهواتف والأجهزة اللوحية والحواسيب.
- صفحات تعليمية منظمة لتسهيل الوصول إلى الدروس.
- دعم الوضع الداكن.
- إمكانية تثبيت المنصة كتطبيق ويب تقدمي (PWA).
- الاهتمام بتحسين الظهور في محركات البحث (SEO).
- اضافه دروس تصميم مواقع اختياريه في html و css و به امثله قابله للنسخ.

## 📚 محتوى المنصة
- الممنوع من الصرف.
- الأسماء الخمسة.
- البدل.
- النعت.

## 🚀 تشغيل المشروع
1. انسخ ملفات المشروع إلى جهازك.
2. افتح مجلد المشروع باستخدام محرر أكواد مثل Visual Studio Code.
3. شغّل المشروع باستخدام إضافة Live Server أو خادم محلي مناسب.
4. لرفع التعديلات، ارفع الملفات إلى مستودع GitHub المرتبط بمشروع Vercel.

## 🎯 الهدف من المشروع
تطوير تجربة تعلم إلكتروني عربية تساعد الطلاب على فهم قواعد النحو والوصول إلى الدروس بسهولة.
